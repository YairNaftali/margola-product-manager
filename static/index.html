How this works

Import a spreadsheet, review each product, then export a Shopify-ready CSV. Nothing reaches Shopify until you choose to sync or export it.

  • No assumed brand or manufacturer data
  • Validation score on every product
  • Drive photo matching + description import
  • 3-product test export before a full push

Resolve photos from Hard Drive

Looks up real photos on the drive using the filelist dumps in your Downloads folder (harddrive_filelist.txt, 2cut_filelist.txt, etc. — see DRIVE_FILELISTS in app.py). No renaming needed. Review the proposed matches below, then upload the ones you want. Requires the drive to be connected for the files it finds.

Color Family + Color Number Tag (Neil's Scheme)

Classifies each approved product's Color Family from its color number/name per Neil's leading-digit scheme, and proposes the Color Number as a plain tag. Review every row before applying — anything the classifier can't confidently place is flagged "needs review" with a blank family for you to fill in or skip.

Shopify export testing

The app is only useful if Shopify accepts the CSV. Test in small batches first.

  1. Approve 2-3 products from the category you're currently working on.
  2. Click Export Shopify Test CSV.
  3. Import that CSV into Shopify.
  4. Check title, variants, prices, weights, metafields, images, and collections.
  5. Only after the test succeeds, use the full Shopify Preview export.
