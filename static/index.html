How this works

Import a spreadsheet, review each product, then export a Shopify-ready CSV. Nothing reaches Shopify until you choose to sync or export it.

  • No assumed brand or manufacturer data
  • Validation score on every product
  • Drive photo matching + description import
  • 3-product test export before a full push

Importing a new category? See NEW_CATEGORY_CHECKLIST.md in the project root.

Push Dimensions sends each variant's Length/Width/Height (from a sheet's dimensions column, if present) to Shopify as custom.length/width/height metafields -- what Calcurates reads for shipping. Only pushes products already imported into Shopify.

Push HS Code / Country of Origin sends each variant's Harmonized System code and Country of Origin (from a sheet's own columns if present, otherwise Neil's category-level defaults in data/hs_code_country_of_origin.json) to Shopify's native customs fields -- what Calcurates reads for Duties & Taxes. Only pushes products already imported into Shopify.

Sync Collections also kicks off watermarking of any new product photos in the background -- see status above. No separate step needed.

Resolve photos from Hard Drive

Looks up real photos on the drive using the filelist dumps in your Downloads folder (harddrive_filelist.txt, 2cut_filelist.txt, etc. — see DRIVE_FILELISTS in app.py). No renaming needed. Review the proposed matches below, then upload the ones you want. Requires the drive to be connected for the files it finds.

Color Family + Color Number Tag (Neil's Scheme)

Classifies each approved product's Color Family from its color number/name per Neil's leading-digit scheme, and proposes the Color Number as a plain tag. Review every row before applying — anything the classifier can't confidently place is flagged "needs review" with a blank family for you to fill in or skip.

Collection Sort Order

Derives a sort order from each product's SKU (color code, and size if the collection spans more than one) and pushes it live. A manual sort is a one-time snapshot, not a live rule — new products just append at the end, so re-run this any time a category gets new colors/sizes. Safe and idempotent.

SEO Title + Description

Regenerates SEO title/description for the whole live catalog straight from Shopify (not just the currently loaded batch) — safe to re-run any time, since a product already having a value isn't proof it's still correct.

Shopify export testing

The app is only useful if Shopify accepts the CSV. Test in small batches first.

  1. Approve 2-3 products from the category you're currently working on.
  2. Click Export Shopify Test CSV.
  3. Import that CSV into Shopify.
  4. Check title, variants, prices, weights, metafields, images, and collections.
  5. Only after the test succeeds, use the full Shopify Preview export.
